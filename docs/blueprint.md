# **App Name**: LuckyDraw

## Core Features:

- QR Code Generator: Generate QR codes that users can scan to join a drawing group.
- User Management: Manage and track users who have joined a drawing via QR code scanning.
- Draw Execution: Initiate a draw from the group of joined users. Send a message to each user indicating whether they are chosen.
- AI Winner Selection: AI tool for picking a winner, ensuring fairness based on participation time using advanced algorithms.
- Live Participant Display: Real-time display of participating users as they join the draw.
- Results Announcement: Display results of the draw with highlighted winners and confetti animations.

## Style Guidelines:

- Primary color: Soft lavender (#D0BFFF) to evoke a sense of calm and anticipation.
- Background color: Very light lavender (#F5F0FF) to keep the interface light and unobtrusive.
- Accent color: Light blue (#A0D2EB) for interactive elements and notifications, complementing the lavender tones with a refreshing contrast.
- Use a clean and modern sans-serif font to ensure readability and a contemporary feel.
- Incorporate simple, line-based icons for easy recognition of functions, maintaining a minimalist aesthetic.
- Maintain a balanced layout with clear spacing to prevent clutter and enhance usability, particularly on mobile devices.
- Implement subtle animations, such as a gentle fade-in effect for newly joined users and a burst of confetti upon revealing the winner, to add delight without distraction.
